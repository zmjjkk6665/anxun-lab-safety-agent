**一、参考方向**：主选「智能制造与系统（SMART SYSTEMS）」，辅选「工程仿真与优化（AI FOR ENGINEERING）」。

**二、问题来源与目标**：高校与科研院所化学实验室的气瓶间、汇流排是可燃气体泄漏高风险点。现行处置依赖人工到场（确认、关阀、排风、疏散），响应有延迟；真实事故常伴随设备失效（如电磁阀电动执行器无响应），缺少备选路径会直接卡死。已有「智能实验室」方案多停留在监测告警，Agent 只给文字建议，无法完成闭环——根因是缺少把模型决策与设备执行可靠连接的运行时。本作品目标：以 Agnes Harness（AGH）为运行底座，让 Agent 完成「感知—判断—执行—复核—报告」闭环，多源交叉确认抑制误报、设备失效自动改派替代路径、以浓度达标为终止条件、全过程 Trace 可审计并自动出具事故报告。

**三、方案概述**：数字孪生一座有机合成实验室（B203），含气瓶间乙炔汇流排、3 台可燃气体探测器、2 台摄像机、温湿度变送器、事故排风、声光报警、安全出口闸机、巡检机器人、应急处置机械臂等共 14 个设备工具；仿真时钟独立线程运行、支持倍速，便于演示与回归测试。

**四、技术架构**：模型负责判断下一步做什么；AGH 负责调用工具、把执行结果回灌给模型并循环推进；业务侧只提供工具注册表与处置规程（Skill），三者解耦，切换 Harness 时业务代码零改动。

**五、AGH 的使用方式**：以 AGH 为智能体运行与执行底座。Harness 的 Agent Loop 以「模型决策 → 工具调用 → 反馈回灌」逐步推进，模型依据上一步真实返回值决定下一步；14 个设备工具经 MCP（stdio + JSON-RPC 2.0）注册给 AGH，由 AGH 编排调用并接收执行反馈；处置规程沉淀为 AGH Skill 跨项目复用。AGH 真机接入（2026-10-14）已完成：源码构建、守护进程与 Web 界面启动、Agnes 模型账号配置与连接测试通过，并在 AGH 会话中完成真实任务。

**六、模型名称 / 版本 / 使用环节 / 调用方式**：Agnes `agnes-3.0-flash`（组委会下发 Key，OpenAI 兼容协议），用于全部决策环节——报警确认、多源交叉验证、切断与改派、排风与疏散、复核观测、事故报告撰写；调用方式为 POST https://api.agnes-ai.cn/v1/chat/completions ，携带 tools 与 tool_choice=auto，温度 0.2；Key 仅由环境变量注入，不写入代码与文档。作品同时支持替换其他 OpenAI 兼容模型。

**七、关键设计**：① 交叉确认：探测器读数 + 摄像机画面 + 机器人现场复测三重确认后才切断，抑制误报；② 失效改派：远程关阀返回失败时自动改派机械臂 ARM-01 就地手动关阀，闭环不中断；③ 达标终止：以源点浓度降至 50 ppm 为终止条件，而非固定步数；④ 失败可见：工具返回 ok=false 并给出原因，绝不静默成功。

**八、运行证据**：AGH 执行记录见 ZIP 内 outputs/agh/agh-execution-record.json（AGH 会话中「规划 → 调用 → 反馈 → 验证」连续步骤原文，含逐项核验结论）；工具调用链见 outputs/traces/ 的 Trace JSON（每步含 thought / tool / args / result / ok / 耗时），典型链路为 read_sensors → get_camera_frame → robot_measure → close_gas_valve（失败）→ arm_manual_shutoff → set_ventilation → start_alarm → broadcast_evacuation → unlock_exit → wait_and_observe → submit_report；模型参与核心任务证据为真机 Trace（14 步 completed、全程未降级，报告由模型自主撰写）；关键配置见 config/default.json 与 deploy/agh/agh.labguard.json；验证结果为端到端断言全部 PASS。

**九、测试样例（正常 / 边界 / 失败）**：① 正常：python run.py cli --mode mock，12 步 completed，阀门关闭、排风 100%、人员疏散、源点浓度降至 50 ppm 以下、报告生成；② 边界：机械臂 arm_manual_shutoff 目标距离超过 3.0 m 时返回 ok=false 并给出「超出可达范围」，拒绝执行而非静默成功；复核阶段浓度趋势停滞或达到最大观测轮次时，据实提交报告并提示人工介入；③ 失败：远程关阀执行器无响应后自动改派机械臂，闭环未中断；Key 失效（401）/ 限流（429）/ 网络不可达时自动降级为内置规则规划器，闭环照常完成并在 CLI 打印降级提示。三类样例由 tests/test_smoke.py 断言，可用 python run.py selftest 复现。

**十、可运行作品**：代码仓库 https://github.com/zmjjkk6665/anxun-lab-safety-agent （Public）；在线体验：python run.py web → http://127.0.0.1:8787 ；安装包为参赛 ZIP；复现命令 python run.py cli --mode mock、python run.py selftest、python run.py mcp --selftest。核心功能零第三方依赖，无 Key 也可离线完整演示。
