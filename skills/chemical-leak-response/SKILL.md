# 化学实验室可燃气体泄漏应急处置

## 适用场景
实验室内可燃/有毒气体探测器报警，或疑似气瓶间、管路、反应装置泄漏的应急处置。

## 处置规程（SOP）

### P1 感知
- 读取全部气体探测器读数与报警等级，记录浓度、位置、时间。
- 读取温湿度，判断是否存在燃爆风险。

### P2 确认（禁止凭单点报警直接停机）
- 调取就近摄像机画面，确认是否有可见烟雾/明火、现场人数。
- 派巡检机器人前往疑似泄漏源现场复测浓度。
- 三点一致（探测器 + 视频 + 机器人复测）方可判定为真实泄漏。

### P3 切断
- 优先远程关闭对应电磁阀/管路阀门。
- 若执行器无响应（返回失败），**立即改派机械臂就地手动关阀**，不得原地反复重试。

### P4 控制
- 启动事故排风至最大档。
- 启动声光报警器。
- 广播疏散指令，说明撤离路线与禁止事项（如禁止使用电梯）。
- 解锁全部安全出口闸机。

### P5 复核
- 等待并持续观测浓度趋势。
- 必须确认浓度持续下降至安全阈值以下；若仍上升，检查阀门与排风状态并补做处置。

### P6 收尾
- 提交事故报告：处置结论、根因分析、处置动作时序、整改建议。

## 硬性约束
- 每次只调用一个工具，依据上一步真实返回值决策，禁止假设设备状态。
- 工具失败必须切换替代手段，同类重试不超过 1 次。
- 涉及人员安全的动作（报警、疏散、广播）优先于设备操作。
- 浓度未达标不得结束任务。
